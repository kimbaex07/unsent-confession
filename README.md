# The Unsent Confession

The message typed a hundred times and never sent.

> To: my best friend from school
> I still type your name first when something good happens, then delete it before I hit send.

**Character count: 122** (gate: 1–260 characters; message line 91 characters, under the 200-character limit).

## Why it lands

The confession is a small, specific habit — typing the name first, then deleting it — which is exactly how an unsent message actually lives: written, then erased, over and over. The reason it stayed in drafts is felt in the words rather than stated: the friendship drifted, the moment to reach out passed, and now sending it feels too late and too strange, so the message gets typed and deleted instead of sent. The To: line and the message need each other: "typing your name first" only aches when it's the person you used to tell everything first, and swapping in any other addressee would break it. No joke, no greeting, no advice — just the honest thing someone typed and never sent.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

Writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (pure Python stdlib, no third-party imports).
